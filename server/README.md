# 本机图片识别服务

需要 Node.js 24。将 `.env.local.example` 复制为 `.env.local`，填写已开通视觉模型的 API Key 和模型 ID。私密配置已被 Git 忽略，整个 server 目录也已排除出小程序打包。

在项目根目录启动：

```sh
node server/vision/server.js
```

服务只监听 `127.0.0.1:8787`。保持进程运行，再在本机微信开发者工具中使用「AI 检查」。客户端地址位于 `config/vision.js`。

当前仅供本机联调，手机无法访问电脑的 127.0.0.1。上线前需部署带鉴权、限流的 HTTPS 后端，并配置小程序合法域名；不要直接将本服务暴露公网。

快速检查使用真实图片调用豆包；分步勘察的 recognize 流程仍使用原演示数据。首页地图为模拟示意图，不提供实际导航。
