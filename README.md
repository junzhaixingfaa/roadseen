# 路见 · 校园无障碍信息平台（微信小程序雏形）

面向轮椅及行动不便人群的校园无障碍地点与通行信息小程序。核心闭环：

**查地点 → 看证据 → 判断能否通过 → 现场采集 → AI 预填 → 人工确认 → 动态上报 → 状态更新 → 分享与复核**

## 开发规划

雏形按 11 个阶段实现（脚手架 → mock 数据与 services → 规则引擎 → 地图搜索 → 通行卡 → 档案 → 勘察拍摄 AI → 动态上报 → 收藏分享消息 → 管理端 → 文档自检），均已完成。

## 如何打开

1. 安装并打开 **微信开发者工具**（建议最新稳定版）。
2. 「导入项目」→ 选择本目录。
3. 若当前 AppID 无权限，请在导入时选择「测试号」；已有团队 AppID 权限时可保留项目配置。
4. 详情 → 本地设置 勾选「不校验合法域名」（雏形使用本地 mock 数据，无网络请求）。

## 当前可演示的完整流程

在开发者工具中依次可走通（对应比赛演示主线九步）：

1. **登录与建档案**：账号密码登录，或注册新账号后设置器具 / 独立或陪同 / 必需设施。
2. **查地点**：地图四色标记 或 搜索筛选 → 打开地点通行卡（结论 + 原因 + 证据 + 步骤 + 事件）。
3. **看变化**：切换「独立 / 有人陪同」，或把档案里的器具宽度改成 78 cm 后返回，通行卡结果与原因按规则改变（实验楼通往实验室的路径最窄处 76 cm，电动轮椅会直接判为不可通行，手动轮椅 70 cm 则正常）。
4. **领任务**：勘察页显示信息缺失的待勘察地点。
5. **引导拍摄**：分步拍照 + 必填校验 → AI 逐项预填（含识别失败可人工填写）。
6. **人工确认提交**：确认 / 修改 / 标未知后提交，进入待审列表。
7. **动态上报**：在「图书馆」通行卡上报「施工封闭」→ 返回地图后该地点由绿变红并重算；「实验楼」预置了电梯停运事件，未建档案的用户同样看到红色（按通用轮椅条件保守假定需乘电梯）。
8. **审核发布与恢复**：管理员账号在「管理端」查看照片和识别字段，通过后发布到地点资料；也可驳回并记录原因、把事件标记恢复 → 消息页收到恢复通知。已过预计结束时间的事件会进入「待复核」，管理员可「确认已恢复」或「仍在进行中」（后者重新生效并清空预计结束时间）。
9. **订阅与分享**：在地点通行卡订阅状态更新 → 消息页按“全部 / 我的关注 / 待复核”筛选并显示未读红点；也可查看自己的上报进度、最近浏览，或生成「同行接力卡」分享给同行人。

地点通行卡的「纠错」也已形成记录闭环：反馈“已经变化”会进入补拍流程，管理员可在「纠错复核」中采纳或忽略并保留处理记录。

## 当前技术约定（雏形阶段）

- 微信小程序**原生框架**，无第三方构建。
- 数据与校园配置全部走 `services/` 数据访问层，读的是 `data/` 本地 mock 数据；页面不直接 import `data/`。后续接入云开发时主要重写 `services/`。
- 通行判断为 `services/ruleEngine.js` **真实规则引擎**（作品核心），可离线自测：`node scripts/selftest.js`（122 项断言，覆盖规则全部分支、事件过期与复核、账号隔离订阅/浏览/已读状态、勘察发布回归）。
- 勘察提交与审核发布逻辑在 `services/inspectionService.js`，同样被离线自测覆盖。
- 结构校验：`node scripts/structcheck.js` 检查 WXML 事件绑定是否都有对应方法、页面跳转目标是否已注册（小程序编译器不检查这两项，绑定名打错只会静默失败）。
- AI 识图/OCR 为 `services/aiService.js` **模拟结果**，用于演示「AI 预填 → 人工确认」流程。
- 采集照片经 `services/fileService.js` 由临时路径转存为本地永久文件，重启后证据不裂图；尚未上传云端。

## 团队协作与版本管理（GitHub）

- 主仓库：GitHub 私有仓库（`origin` 已关联）；`main` 始终为可跑通的稳定版。
- 分支：`feat/*` 做功能，`fix/*` 做修复，`docs/*` 做文档。
- 合并：feature → Pull Request → 另一人 review + 本地 `node scripts/selftest.js` 全绿 → 合并 `main`。
- Commit 前缀：`feat:` `fix:` `docs:` `refactor:` `data:` `chore:`。
- 进度看板见 [`开发进度.md`](./开发进度.md)，随代码一起提交。
